# Download Kraken Player

Get the latest version for your system on the **[Releases](https://github.com/zodd95x/kraken-player/releases)** page:

| System  | Files                                                     |
| ------- | --------------------------------------------------------- |
| Windows | `KrakenPlayer-*-setup.exe` (installer) or `*-portable.exe` |
| macOS   | `KrakenPlayer-*.dmg` (Intel and Apple Silicon)            |
| Linux   | `.AppImage`, `.deb`, `.rpm`, `pacman` or `.tar.gz`        |

Prefer building from source?

```bash
pnpm install
pnpm build:win
```
